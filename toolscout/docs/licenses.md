**Notes:**
- **GitHub Copilot** is MIT-licensed (source: GitHub Primer Octicons). The license text is in `assets/logos/LICENSES.txt`.
- **Mailchimp** is shown in its dark color (#241C15) instead of yellow, for contrast on a white background. ⚠️ Check this against the brand assets (https://mailchimp.com/about/brand-assets) before launch.
- **OpenAI** is shown in monochrome, because OpenAI's brand guidelines forbid adding colors to the mark. The guidelines also say that using the logos means agreeing to OpenAI's Marks usage terms, and that permission can be revoked. ⚠️ **The owner should review this before launch.**
- **Figma**'s guidelines allow informational use and links. Uses they don't cover require approval (press@figma.com).
- **Brands with no logo** (Microsoft Copilot, Mistral Vibe, DeepSeek, QuillBot, Midjourney, Runway, Descript, HeyGen, Cursor, Visual Studio Code, Otter.ai, Ideogram, CapCut, Synthesia, Fireflies.ai, Windsurf, Krisp, Proton Pass, Jasper, monday.com, Leonardo.ai) are shown with initials generated by ToolScout, not with their logo.
- ⚠️ **Not yet reviewed:** the brand guidelines of the other brands (Anthropic/Claude, Google/Gemini, Adobe, Canva, Notion and others). Reviewing them is a pre-launch task for the owner.
